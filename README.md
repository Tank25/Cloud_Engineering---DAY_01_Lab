Today I learned the fundamentals of Cloud Engineering, Linux command-line operations, Git, and Infrastructure as Code using Terraform.

### 🖥️ Linux & Terminal

I learned how to work with the terminal and navigate a Linux environment. I practiced identifying my current user and computer, checking my current directory, navigating between directories, and creating files and folders.

Some of the commands I practiced include:

* `whoami` — identify the current user
* `hostname` — identify the computer
* `pwd` — show the current directory
* `ls` — list files and directories
* `cd` — navigate between directories
* `mkdir` — create directories
* `touch` — create files

### 🌿 Git & Version Control

I learned the purpose of Git and how it is used to track changes in a project. I learned how to initialize a Git repository, check the status of files, stage changes, and create commits.

I practiced commands such as:

* `git init`
* `git status`
* `git add .`
* `git commit`
* `git log`

I also completed a project structure that included a README file and Terraform configuration.

### 🏗️ Infrastructure as Code & Terraform

I learned the basic concept of Infrastructure as Code (IaC), where infrastructure can be defined and managed using configuration files instead of creating everything manually.

I learned that Terraform is an Infrastructure as Code tool used to define and manage infrastructure.

I created a basic Terraform configuration and learned how to initialize and validate a Terraform project.

The main Terraform commands I practiced were:

* `terraform init` — initialize a Terraform project
* `terraform fmt` — format Terraform configuration
* `terraform validate` — check whether the configuration is valid
* `terraform plan` — preview infrastructure changes

### 🐛 Troubleshooting

I also learned how to troubleshoot a simple Terraform configuration error. I intentionally introduced an error into `main.tf`, ran `terraform validate`, read the error message, identified the problem, corrected the configuration, and validated it again.

This helped me understand that error messages are useful for identifying and fixing configuration problems.

### 📚 Overall Learning

By the end of this lesson, I gained a basic understanding of:

* Linux terminal navigation and commands
* File and directory management
* Git and version control
* Git repositories, staging, and commits
* Infrastructure as Code
* The purpose of Terraform
* Terraform project initialization
* Terraform configuration validation and formatting
* Terraform planning and basic state concepts
* Reading and troubleshooting configuration errors

This lesson gave me a strong foundation for continuing my Cloud Engineering journey and learning how cloud infrastructure can be managed through code.
